# Minor update 1.6.1 is released

**_Your Easy Solution for PDF Accessibility validation._**

Dual Lab is ready to announce the new release of **PDF4WCAG Accessibility Checker 1.6.1.**

This release includes **several  Web UI and desktop improvements** and minor bug fixes to ensure more reliable and accurate PDF accessibility checks.

**Desktop updates:**

- More user friendly error message when the application cannot find Java
- Recent security updates for 3rd party libraries
- Corrected Privacy policy

**PDF viewer updates:**

- Fix in bounding box rendering
- Updated bounding box styles to fix visual appearance of overlapping boxes

**Validation updates:**

- Fixed the check for a non-standard structure type not mapped to a standard type
- Fixed unwanted MathML errors in WCAG (Machine) profile
